# Сайт «Альфа Машинери»

Статический многостраничный сайт официального дилера **UMG** и **ВПК (ЗЗГТ)**:
каталог техники с вложенностью бренд → категория → модель, запчасти, сервис,
лизинг, контакты.

Готовые HTML-файлы лежат в корне — сайт можно просто залить на любой хостинг
или открыть `index.html` двойным кликом. Никакой сборки при просмотре не нужно.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html`, `parts.html`, `service.html`, `financing.html`, `about.html`, `contacts.html`, `404.html` | основные страницы |
| `catalog/` | каталог: `catalog/<бренд>/<категория>/<модель>.html` |
| `assets/css/main.css` | вся вёрстка и дизайн-система по брендбуку |
| `assets/js/site.js` | меню, галерея, табы, фильтры, формы |
| `assets/js/config.js` | контакты и адрес формы — **генерируется**, править не нужно |
| `assets/img/machines/` | фотографии техники |
| `assets/img/brand/` | логотипы и фавиконки |
| `assets/fonts/` | Montserrat и Inter локально, без внешних CDN |
| `data/site-config.json` | **контакты и реквизиты — правьте здесь** |
| `data/catalog.json` | номенклатура: ТТХ, описания, фото |
| `_build/` | скрипты сборки |

## Что нужно заполнить

Откройте `data/site-config.json`:

- `address`, `city` — адрес офиса (сейчас заглушка);
- `inn`, `ogrn` — реквизиты, если нужны в подвале и на контактах;
- `formEndpoint` — адрес обработчика форм (см. ниже);
- `messengers.telegram` — если нужна кнопка Telegram.

После правки пересоберите страницы:

```bash
python3 _build/generate.py
```

## Как включить отправку заявок

Пока `formEndpoint` не заполнен, формы честно говорят посетителю, что отправка
не настроена, и предлагают почту и телефон — заявки не теряются молча.

Чтобы письма приходили на `alfa-mash@bk.ru`:

1. Зарегистрируйтесь на [formspree.io](https://formspree.io) и создайте форму
   с этой почтой.
2. Скопируйте выданный адрес вида `https://formspree.io/f/xxxxxxxx`.
3. Вставьте его в `formEndpoint` в `data/site-config.json`.
4. Пересоберите: `python3 _build/generate.py`.

## Как обновить каталог

Данные и фотографии берутся с сайтов производителей.

```bash
python3 _build/scrape.py      # заново обходит umg-sdm.com и zzgt.ru, ~15 минут
python3 _build/generate.py    # пересобирает HTML
python3 _build/check.py       # ищет битые ссылки и картинки
```

`scrape.py` не перекачивает уже сохранённые фото, поэтому повторные запуски
проходят быстро. Список категорий и моделей задаётся в начале файла —
`UMG_CATEGORIES` и `ZZGT_MODELS`.

В галерею модели попадают первые 8 фотографий, остальные остаются в
`assets/img/machines/` про запас. Если хотите отдать хостингу только нужное,
поднимите или опустите лимит в `_build/generate.py` (`item["photos"][:8]`).

Чтобы добавить модель, которой нет на сайтах производителей, допишите её прямо
в `data/catalog.json` по образцу соседней записи и запустите `generate.py`.
Но учтите: следующий запуск `scrape.py` перезапишет каталог.

## Локальный просмотр

```bash
python3 _build/serve.py
```

Затем откройте <http://localhost:8123>.

## Фирменный стиль

Цвета и геометрия заданы переменными в начале `assets/css/main.css`:
графит `#1a1a1a`, Альфа Грин `#39ff14`, белый `#ffffff`, диагонали 30°,
гексагональная текстура. Логотип вырезан из макета брендбука скриптом
`_build/make_brand_assets.py` — если появится исходник в векторе, замените
файлы в `assets/img/brand/`.
